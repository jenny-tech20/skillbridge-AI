# SkillBridge AI

SkillBridge AI is a student career and skill-gap analysis platform built using Python and Flask.

## Features

- Student profile creation
- Skill analysis
- Career readiness score
- Matched skill identification
- Missing skill identification
- Career recommendations
- Career match percentage
- Personalized learning roadmap
- Responsive web interface

## Technologies

- Python
- Flask
- Pandas
- HTML
- CSS
- Jinja2

## Career Roles

The current system supports:

- Data Scientist
- AI Engineer
- Web Developer
- Machine Learning Engineer
- Data Engineer
- software Developer
- Python Developer
- Business Analyst
- Cybersecurity Analyst
- Cloud Engineer
- Data Analyst
